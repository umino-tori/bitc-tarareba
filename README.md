# BTCタラレバ長者 vs 現実の地獄シミュレーター

> BTC-JPY の過去価格データを使い、「夢の理論値」と「手数料・ロスカットによる現実」を3つのシナリオで比較するWebシミュレーターです。

---

## 実行環境

| 項目 | 内容 |
|------|------|
| Python | 3.12 以上推奨 |
| 仮想環境 | `.venv`（venv） |
| データ保存 | SQLite3（`btc_data.db`） |
| データ取得 | yfinance（BTC-JPY 日足OHLC） |

### 主な依存ライブラリ

```
streamlit
yfinance
plotly
pandas
```

---

## セットアップ

### 1. リポジトリをクローン

```bash
git clone <repository-url>
cd bitcoin
```

### 2. 仮想環境の作成と有効化

```bash
python -m venv .venv

# Linux / macOS
source .venv/bin/activate

# Windows
.venv\Scripts\activate
```

### 3. 依存ライブラリのインストール

```bash
pip install -r requirements.txt
```

---

## 起動方法

### アプリを起動する

```bash
streamlit run app.py
```

起動後、ブラウザで `http://localhost:8501` が自動的に開きます。

### （任意）DBを事前に初期化する

アプリ起動前にコマンドラインでデータを取得・保存したい場合:

```bash
python init_db.py
```

過去5年分の BTC-JPY 日足データを yfinance から取得し、`btc_data.db` に保存します。
アプリ上のサイドバーボタンからも同じ操作が可能です。

## 機能一覧

### サイドバー設定（地獄の調整ツマミ）

| 設定項目 | デフォルト値 | 範囲 |
|---------|------------|------|
| 期間設定 | 過去1年 | 過去1年 / 3年 / 5年 / 年月日指定 |
| 初期資金（円） | 1,000,000 | 1万〜10億 |
| 手数料 Maker/Taker（%） | 0.1% | 0〜5% |
| スリッページ（%） | 0.5% | 0〜5% |
| レバレッジ倍率 | 1倍 | 1〜100倍 |
| 強制ロスカットライン（証拠金維持率 %） | 50% | 10〜100% |

### 3つのシミュレーションシナリオ

#### A: 神の現物（Dream）
- 毎日「最安値で買い・最高値で売る」神業トレードの理論最大値
- 手数料・スリッページ: ゼロ
- 損益を毎日累積加算

#### B: 現実のトレード（Reality）
- Aと同じトレードロジックだが、毎回手数料とスリッページが発生
- コスト = `(手数料% + スリッページ%) × 2`（買い・売り各1回）
- AとBの差額 = 「手数料・スリッページによる損失総額」として表示

#### C: レバレッジ・ガチホ（Hell）
- 初日終値でロングポジションを保持し続ける（Buy & Hold）
- 資産変動 = 価格変動率 × レバレッジ倍率
- 証拠金維持率がロスカットラインを下回った瞬間に資産ゼロで退場

### グラフ・表示

| 表示要素 | 内容 |
|---------|------|
| ローソク足チャート | BTC-JPY の日足OHLC + 日次損益ライン（上下2段） |
| 資産推移グラフ | A/B/C の資産額を重ねて表示。ロスカット地点に💀注釈 |
| シミュレーション結果 | 最終資産額・リターン率を3列で比較表示 |
| 手数料損失表示 | AとBの差額を赤字で表示 |
| 警告メッセージ | ロスカット発動・追証発生時に警告バナーを表示 |
| 円グラフ | シナリオ別に元本・利益・損失の内訳を表示 |
| 日次詳細テーブル | 各日の売買価格・手数料・損益累計を一覧表示（スクロール可） |

### データ管理

- サイドバーの「📥 過去5年分のBTCデータを取得・更新」ボタンで最新データを取得
- データは `btc_data.db`（SQLite）にキャッシュされ、再取得ボタンを押さない限り再利用
- DB最終取得日付をサイドバーに表示

---

## 注意事項

- 本アプリは過去のBTC-JPY価格データに基づく**理論値シミュレーション**です
- 実際の取引結果を保証するものではありません
- データ取得にはインターネット接続が必要です（yfinance 経由）
